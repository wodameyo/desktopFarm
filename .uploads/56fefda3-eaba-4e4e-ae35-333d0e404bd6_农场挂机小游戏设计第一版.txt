# 项目：像素农场挂机小游戏（Idle Farm）

## 1. 项目定位
- 一款 2D 平面像素画风格的农场挂机（Idle/放置）小游戏，用于上班间隙挂机消磨时间。
- 玩法基调参考《星露谷物语》，但大幅降低操作频率：不需要操控主角，玩家以"上帝视角"用鼠标管理农场，多数时间看着农场自动运转。
- 单机运行，无联网、无账号系统。

## 2. 技术规格（硬性要求）
- 载体：Windows 桌面窗口程序（独立窗口应用，双击 exe 启动，非浏览器网页）。
- 推荐技术栈：Electron（HTML + Canvas + JS 渲染游戏画面，外层为桌面窗口壳）。
  - 备选方案：Python + Pygame（更轻量、纯代码、适合像素游戏）；Tauri（打包体积最小，需 Rust 工具链）。
- 窗口能力：
  - 启动为独立桌面窗口，支持鼠标拖拽调整窗口大小，设置最小尺寸（如 640×480）防止画面过小。
  - 提供"窗口置顶"开关（always-on-top），开启后窗口固定在桌面最上层，便于上班时挂在屏幕角落。
  - 提供 1x/2x/3x 画面缩放设置；缩放采用 nearest-neighbor 整数倍放大，像素画不模糊。
- 输入：仅鼠标操作（点击、悬停提示）；无键盘依赖、无主角移动。
- 存档：本地 JSON 存档文件（保存于用户数据目录，如 %APPDATA% 下），启动自动读取、运行中每 30 秒自动保存 + 手动保存；关闭重开进度不丢。
- 分发：最终打包为可双击运行的 Windows 可执行程序（.exe）。

## 3. 核心玩法系统
### 3.1 种植系统（主循环核心）
- 田地按格子划分，初始 16 格（4×4），每格 3 种状态：空地 / 耕地 / 已种作物。
- 操作链：点击空地开垦 → 点击种子播种 →（自动或点击）浇水 → 等待生长 → 成熟后点击收获。
- 至少 6 种作物：小麦、胡萝卜、番茄、草莓、南瓜、玉米；每种有独立的生长时间、售价、季节限制、像素外观（含生长阶段动画：种子→发芽→成长→成熟）。
- 支持"一键收获""一键补种"按钮，降低重复操作。

### 3.2 经济系统
- 金币：收获出售获得，是唯一货币；开局给予少量启动资金。
- 商店：购买种子、田地扩展券、装饰物、机器人；展示价格与成长周期，作物购买/售价比与利润一目了然。

### 3.3 扩张系统
- 用金币购买相邻田地格子，每格价格随购买数量递增；可解锁新区域（池塘边、果园、温室）。
- 扩张是中期主要金币消耗与成长感来源。

### 3.4 装饰系统
- 商店出售栅栏、路灯、花坛、雕像、稻草人等装饰物，鼠标点击放置到空地。
- 装饰纯视觉为主，少量装饰可提供小加成（如稻草人防虫、花坛加速附近生长）。

### 3.5 机器人系统（后期解锁，简化操作）
- 商店解锁"自动机器人"系列：浇水机器人→自动浇水；播种机器人→自动补种；收获机器人→自动收获并出售。
- 逐级购买，后期实现全自动挂机，玩家只负责规划、扩张与升级决策。

### 3.6 时间与天气系统（自动运转，无需操作）
- 昼夜更替：游戏内 1 天 = 现实 5 分钟（可在设置调整）；夜晚画面变暗、路灯亮起。
- 四季循环：春夏秋冬各 15 游戏日，每个季节草地/树叶配色变化，不同作物限季种植，换季时未收作物枯萎。
- 天气：晴天/雨天/雪天随机出现；雨天自动浇水，雪天生长速度减半，天气影响画面粒子效果（雨滴/雪花）。

## 4. 挂机机制（核心定位）
- 在线挂机：游戏窗口打开时持续推进，作物持续生长。
- 离线收益：关闭游戏后按离线时长折算 50% 的种植产出，回到游戏时一次性结算（依据存档时间戳计算）。
- 低操作频率：目标为"每 5~10 分钟看一眼"；成熟作物有醒目标记（闪光/提示音可选）。

## 5. UI 与交互
- 顶部信息栏：金币、当前日期、季节、天气、时间（游戏内）。
- 鼠标悬停显示作物/建筑信息；点击执行所有操作；提供"一键收获/补种"。
- 商店面板、设置面板（音乐/音效开关、画面缩放、窗口置顶开关、存档管理）。

## 6. 验收标准（生成后必须满足）
1. 双击 exe 直接进入游戏，核心循环"种→长→收→卖→扩张"完整闭环。
2. 窗口可自由缩放（含最小尺寸限制），像素画面整数倍缩放不模糊。
3. "窗口置顶"开关生效，窗口可固定在桌面最上层。
4. 昼夜、四季、天气三种时间系统真实生效并影响游戏。
5. 关闭游戏重开后，进度从本地存档文件完整恢复。
6. 机器人解锁后能实现对应自动化操作。

## 7. 开发优先级（可分期实现）
- P0（第一版）：桌面窗口骨架、田地、3 种作物、种/收/卖、金币、昼夜循环、本地文件存档。
- P1（第二版）：四季、天气、扩田、商店完整化、一键收获、窗口置顶开关。
- P2（第三版）：装饰、机器人、离线收益、音效与动画打磨、exe 打包分发。
